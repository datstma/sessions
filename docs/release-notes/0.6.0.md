# Sessions 0.6.0 Alpha

Mark apps optional, duplicate Sessions, and pick up where you left off.

Sessions is in Alpha: its core workflow is available for everyday testing, while
features and saved-data formats may change. Feedback and bug reports are welcome.

## Changes

- **Optional apps.** In an app's options, turn on **Continue if this app doesn't
  start**. If that app can't open (for example a missing file, a Windows error,
  cancelled administrator approval or an unavailable plugin) or doesn't meet its
  startup condition, the Session carries on without it and tells you why. Anything
  it did open still closes when the Session ends. If the app that ends the Session is
  skipped, you end the Session yourself. Detail cards label optional apps.
- **Duplicate Session.** Copy a Session's apps and settings into a new draft named
  "<name> copy". Nothing is saved until you create it, and the copy appears right after
  the original, fully independent of it.
- **Pick up where you left off.** Sessions reopens with its last window size, position
  and maximized state, fitted to your current displays, and selects the Session you
  were viewing.
- **About Sessions** at the end of Settings shows the version and project stage, links
  to release notes, issues and source code, your data folder, and a **Licenses and
  notices** window that shows the Sessions license and bundled third-party notices.
- **Library backups on upgrade.** The first time you save a library created by an
  earlier version, Sessions keeps a copy of the previous file and shows where it is.
- **A roomier layout.** Session details and the editor use space more efficiently, so
  typical Sessions fit without scrolling. Text is centered in buttons and fields,
  running and background-only apps share one status style, and expandable sections no
  longer show a separate highlight on their arrow.
- **Fixed:** in app options, the explanations under **Run as administrator** and
  **Force quit if this app stays open** had been swapped since 0.2.2.

## Compatibility

**Saving a library in 0.6.0 writes format v6. Sessions 0.5.0 and earlier cannot read
v6.** Opening an older library does not change it. The first save afterwards (an edit,
new Session, duplicate or deletion) keeps the previous file beside your library as
`sessions.v<old version>-backup-<date>-<time>.json` and shows its location. To return
to an earlier release, close Sessions and restore that copy as `sessions.json`; changes
made after upgrading are not in the copy.

Window placement is stored separately in `%LOCALAPPDATA%\Sessions\window.json` and is
ignored if unreadable. Appearance and plugin preferences are unchanged.

## Validation and Alpha limits

Local installer validation passes clean solution/MSI builds, self-contained Windows
x64 publishing, dependency-notice collection and WiX validation, plus 150 Core and 266
App tests (31 opt-in native skips). New automated coverage includes optional-app
startup (skips, tracked apps missing their condition, main-app fallback, concurrent and
untracked launches, unavailable plugins and cancellation), loading every library format
from v1 to v6 and the upgrade backup, duplication identities, window placement across
changed, removed and mixed-scaling displays, About actions and the licenses viewer, and
text centering and default-window fit in both themes.

The maintainer tried each feature in a source build before release. Real-app
confirmation does not yet cover optional apps with cancelled administrator approval,
readiness timeouts or skipped Steam apps, window restoration across multiple monitors
or display-scaling changes, or the full third-party notices list in an installed build.

Real Steam save prompts and cleanup edge cases, native Narrator, physical-monitor/DPI
changes, ordinary nonadministrator installation and installed real-app/UAC behavior
remain validation limits. Installer lifecycle checks are not repeated for this release,
following the maintainer's existing request. MSI and app binaries are unsigned.

## Upgrading

Close Sessions and run `Sessions-0.6.0-win-x64.msi`. The per-user Windows x64 installer
includes .NET and preserves saved Sessions, appearance and plugin preferences.
There is no automatic updater.

## Source and checksums

`Sessions-0.6.0-source.zip` contains matching GPL-3.0-only Sessions source and build
scripts. Dependency notices are installed in `licenses` and can be read from
Settings → About Sessions → Licenses and notices. `WiX-7.0.0-source.zip` supplies the
embedded installer utility action's matching MS-RL source. `SHA256SUMS.txt` covers the
MSI and both source ZIPs.
