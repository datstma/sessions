# Sessions 0.4.0 Preview

Make Sessions comfortable for you with local appearance preferences.

## Changes

- Open **Settings** from the sidebar or the empty-library header. The separate
  window keeps your Session draft and active run intact.
- Choose **System**, **Light** or **Dark**. System follows Windows theme changes.
- Set interface size to 100%, 110%, 125% or 150%, and text size independently to
  100%, 110% or 125%. Interface enlargement fits the available window space;
  at the 640×480 main-window minimum it stays at 100%, with text sizing still applied.
- Preview choices before **Apply preferences** saves and updates open windows.
  **Reset preferences** restores System and 100% sizing while keeping saved Sessions.
- Recover from unreadable preferences with retry or an explicit reset that backs
  up the original file. Failed saves keep the current appearance and choices for retry.
- Keep the New Session label readable at larger text sizes, and scale first-run
  line heights with typography.
- Explicitly type the selected-Session binding source for Rider's XAML inspection.

The maintainer confirmed Settings works and separately confirmed Playnite closes
successfully with force quit. This records validation of existing force-quit behavior;
it does not introduce broader process ownership or process-tree termination.

## Compatibility

Appearance preferences are stored separately in
`%LOCALAPPDATA%\Sessions\preferences.json`. Settings does not change Session definitions.
Plugin management, tray/startup behavior and arbitrary font selection remain future work.

The Session library remains format v4, shared with 0.3.0. **Sessions 0.2.3 and earlier
cannot read v4.** Older libraries load without rewriting until saved. Keep a copy of
`%LOCALAPPDATA%\Sessions\sessions.json` before saving if you need to return to an older build.

## Validation and preview limits

The local installer build passed with zero solution/MSI warnings or errors,
self-contained Windows x64 publishing, dependency-notice collection and WiX validation.
Validation includes 74 Core tests and 177 App tests
(27 opt-in native skips), including preference persistence, recovery, save failures,
keyboard interaction, drafts and active runs. Both themes at 1440×900 and 640×480,
plus 125%, 150% and 200% headless rendering, were checked and captures reviewed.

Native Narrator, physical-monitor/DPI changes, Windows text-size settings, ordinary
nonadministrator installation and installed real-app/UAC checks remain separate
validation limits. The Playnite report does not distinguish automatic per-app force
quit from the targeted action or establish graceful-only closing or unsaved-document safety.
Installer lifecycle checks are not repeated for this release, following the
maintainer's request after successful installer/uninstaller use.

The MSI and application are unsigned.

## Upgrading

Close Sessions and run `Sessions-0.4.0-win-x64.msi`. The per-user Windows x64
installer includes .NET and preserves your saved Sessions and appearance preferences.
There is no automatic updater.

## Source and checksums

`Sessions-0.4.0-source.zip` contains the matching GPL-3.0-only Sessions source and
build scripts. Dependency notices are installed in `licenses`.
`WiX-7.0.0-source.zip` supplies the embedded installer utility action's matching
MS-RL source. `SHA256SUMS.txt` covers the MSI and both source ZIPs.
