# Sessions 0.3.0 Preview

Give each Session its own sound output and microphone setup.

## Changes

- Choose output and input independently in the editor's **Session audio** section,
  with **Leave unchanged** as the default. Refresh discovers active Windows devices;
  saved unavailable devices remain visible instead of silently selecting another.
- Apply Windows ordinary and communication defaults before apps launch. Apps with
  their own explicit device selection may keep it; other apps following Windows
  defaults are affected too.
- Restore previous defaults on End Session, including when apps remain open.
  Finish and leave apps open, and Leave apps open and close, also restore audio.
- Preserve later differing device choices, including linked Windows ordinary roles.
  Failed restoration keeps the run available for explicit retry.
- Stop startup on missing devices or failed switching and roll back partial changes.
  Audio choices participate in existing unsaved-edit protection.

## Compatibility

Saving uses library format v4. **Sessions 0.2.3 and earlier cannot read v4.**
Older libraries load without being rewritten until you save. Before saving, keep a
copy of `%LOCALAPPDATA%\Sessions\sessions.json` if you need to return to an older build.

Audio switching uses an undocumented Windows policy interface. This feature changes
system defaults, not individual-app routing, volume or effects. Restoration state is
in memory: a crash, forced termination or shutdown cannot restore previous devices.

## Validation and preview limits

The local release build passed with zero solution/MSI warnings or errors,
74 Core tests and 153 App tests passing (27 opt-in native skips). Self-contained
Windows x64 publishing, dependency-notice collection and WiX MSI validation passed.

The maintainer confirmed Session audio works in a hands-on trial. Automated checks
cover lifecycle ordering, cancellation, partial failures, restoration retry, saved
settings, draft protection and keyboard interaction in both themes and compact layouts.
Two native audio checks passed, including a brief alternate-output switch through
the real runner and verification that all original output roles were restored.

Physical disconnect/reconnect, detailed physical/virtual playback and microphone
checks, ordinary nonadministrator installation, installed real-app/UAC cancellation,
Narrator and physical-monitor checks remain separate validation limits.
Installer lifecycle checks are not repeated for this release, following the
maintainer's request after successful installer/uninstaller use.

The MSI and application are unsigned.

## Upgrading

Close Sessions and run `Sessions-0.3.0-win-x64.msi`. The per-user Windows x64
installer includes .NET and preserves your saved Sessions. There is no automatic updater.

## Source and checksums

`Sessions-0.3.0-source.zip` contains the matching GPL-3.0-only Sessions source and
build scripts. Dependency notices are installed in `licenses`.
`WiX-7.0.0-source.zip` supplies the embedded installer utility action's matching
MS-RL source. `SHA256SUMS.txt` covers the MSI and both source ZIPs.
