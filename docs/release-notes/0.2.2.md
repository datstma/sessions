# Sessions 0.2.2 — Preview (upcoming)

Safer app closing, recognizable app icons, and protection for Session edits.
This version is prepared in source and has not been published.

## What's new

- End Session requests a normal close and leaves apps open when they need more
  time, including apps waiting for you to save a document. Bring an app forward,
  retry closing, or finish and leave its apps open. Force quit requires an explicit
  choice for that app unless you enable **Allow force quit** in its options.
  Apps that were already running remain independent.
- App cards show their executable's icon, with a name initial as the fallback
  when an icon cannot be read.
- Closing with a changed Session draft offers **Keep editing**, **Discard** and
  **Save**. Keep editing is the default. Failed saves retain your edits and allow
  retry; unchanged drafts need no prompt. An active Session's close choices follow
  after resolving the draft.

## Upgrading

Once published, close Sessions and run `Sessions-0.2.2-win-x64.msi`. The per-user
installer includes .NET and preserves your saved Sessions. There is no automatic
updater.

**Saving now uses library format v3, which 0.2.1 and earlier cannot open.** Existing
v1/v2 libraries load without being rewritten and default to normal app closing,
with automatic force quit disabled. Keep a copy of
`%LOCALAPPDATA%\Sessions\sessions.json` before saving if you need to return to an
older release.

## Preview limitations

- Windows x64 only; installer and application binaries are unsigned.
- Force quit can lose unsaved work. Normal close lets each app handle its own save
  prompts; Sessions does not inspect documents for unsaved changes.
- Draft protection applies to window closing. Editor Cancel explicitly discards
  edits; crash recovery and autosave are not included.
- Microsoft Store/packaged-app activation and general launcher handoffs remain
  unsupported. Readiness checks do not prove loading or sign-in has finished.
- Native screen-reader output, physical monitor/DPI changes, Windows text sizing,
  ordinary nonadministrator installation and installed real-app/UAC behavior need
  further hands-on verification.

## Validation

Local Release solution build passed with zero warnings/errors; 54 Core tests and
125 App tests passed, with 25 opt-in native cases skipped. Draft-close coverage
includes invalid/reverted edits, save failures, repeated closing during saves,
keyboard/focus behavior and active-run confirmation ordering. Both themes were
reviewed at 1440×900 and 640×480 with 100/125/150/200% headless scaling.
Local 0.2.2 MSI packaging also passed with zero warnings/errors, and the published
payload's executable reports version 0.2.2. These are local preparation checks.

The user confirmed safer closing works, app icons work and look great, and draft
protection works. Exact published-installer lifecycle validation is still pending
for 0.2.2; prior 0.2.1 installer results do not establish those checks for this build.
