# Sessions 0.5.0 Preview

Add Steam apps to your Sessions and close individual running apps from their cards.

## Changes

- **Settings → Plugins** lists bundled plugins, their versions, enable choices and
  supported settings. Steam is enabled by default, with an optional installation
  folder override. Plugin preferences have separate Apply and Reset controls.
- **Add app → Plugins** discovers installed Steam apps across local libraries.
  Sessions sends launch requests through Steam and shows Steam's running status.
- Enable **Close when this Session ends** in a Steam app's options to let Sessions
  close verified processes it opened. This is off by default. Already-running apps
  and the shared Steam client stay open during automatic Session cleanup.
- Use **Close…** beside a running ordinary or Steam app to close it individually,
  including apps opened outside Sessions. The named-app confirmation starts on
  Cancel and asks you to save your work. It requests normal closing, preserves
  later copies and other apps, and does not automatically force quit.
- Closing one app keeps the Session active. Closing its tracked main app uses the
  existing end-confirmation flow.
- Launch and close acknowledgements use neutral feedback, with errors kept separate.
  Feedback clears as running-state checks confirm the requested change. Running
  and Close controls align at compact and full window sizes.

The maintainer tested 3DMark launching/running detection, confirmed the launch-feedback
fix, and reported improved individual closing after the alignment/status correction.
These reports do not establish every Steam cleanup or unsaved-work edge case.

## Compatibility

**Saving a library in 0.5.0 writes format v5. Sessions 0.4.0 and earlier cannot read
v5.** Loading v1–v5 does not rewrite the library. Keep a copy of
`%LOCALAPPDATA%\Sessions\sessions.json` before saving if you need to return to an
older release. Plugin choices use stable app IDs rather than machine-specific paths.

Plugin preferences are stored separately in `%LOCALAPPDATA%\Sessions\plugins.json`.
Appearance preferences and Session audio choices are retained. This release bundles
trusted in-process plugins; third-party loading, a marketplace, Hue and Home Assistant
are not included.

## Validation and preview limits

[The tagged release workflow](https://github.com/datstma/sessions/actions/runs/34516646243)
passed clean solution/MSI builds, 119 Core and 224 App tests (31 opt-in native skips).
Downloaded checksums verify, all 214 source archive entries match v0.5.0, and the MSI
reports ProductVersion 0.5.0. Matching WiX source and license checks also pass.

Local installer validation passes clean solution/MSI builds, self-contained Windows
x64 publishing, dependency-notice collection and WiX validation, plus 119 Core and 224 App
tests (31 opt-in native skips). Both themes, 1440×900/640×480 layouts, enlarged text
and 125/150/200% headless scaling are covered. Separate native checks use isolated
hidden helpers and synthetic Steam logs to verify normal closing, pre-existing
process protection during Session cleanup, fixed targets for individual Close,
Cancel preservation, and survival of later copies and apps in other folders.
Read-only discovery also exercised the installed Steam client. Automated checks
never launched or closed real Steam apps.

Steam running/tracking depends on undocumented local registry/log formats. Startup
tracking is bounded to 30 seconds; late launches, outside-directory helpers or
unverifiable identities can need manual management. Individual Close requires active
process records in the final 1 MiB of Steam's log. When it cannot verify targets,
close the app from its own window or Steam. Running status alone grants no ownership.
Steam main-app lifetime, completion focus and custom launch arguments are unavailable.

Real Steam save prompts and cleanup edge cases, native Narrator, physical-monitor/DPI
changes, ordinary nonadministrator installation and installed real-app/UAC behavior
remain validation limits. Installer lifecycle checks are not repeated for this
release, following the maintainer's existing request. MSI and app binaries are unsigned.

## Upgrading

Close Sessions and run `Sessions-0.5.0-win-x64.msi`. The per-user Windows x64 installer
includes .NET and preserves saved Sessions, appearance and plugin preferences.
There is no automatic updater.

## Source and checksums

`Sessions-0.5.0-source.zip` contains matching GPL-3.0-only Sessions source and build
scripts. Dependency notices are installed in `licenses`. `WiX-7.0.0-source.zip`
supplies the embedded installer utility action's matching MS-RL source.
`SHA256SUMS.txt` covers the MSI and both source ZIPs.
