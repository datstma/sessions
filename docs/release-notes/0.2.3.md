# Sessions 0.2.3 Preview

This patch makes it easier to find and correct Session settings that prevent saving.

## Changes

- Required names, executable paths, app choices and startup values now explain
  what needs fixing beside the affected field.
- **Review fields** beside Save selects the affected app, opens its options and
  brings the field and explanation into view with keyboard focus.
- App rows identify invalid settings even when their options are collapsed.
- Invalid timing values stay accessible after switching startup options off.
  Correcting them preserves the selected options and other draft values.
- Paths on disconnected drives remain saveable. Availability is checked when
  launching an app.

## Compatibility

The saved-library format remains version 3, as in 0.2.2. Published 0.2.1 and older
builds cannot read that format. Installation and uninstall preserve saved Sessions.

## Validation and preview limits

The maintainer confirmed the editor changes work in their hands-on trial. Automated
coverage checks validation, keyboard navigation, correction and offline-path saving,
with both themes and compact layouts at 100%, 125%, 150% and 200% headless scaling.

The local release build passed with zero solution/MSI build warnings or errors,
54 Core and 141 App tests passing, and 25 opt-in native tests skipped. Self-contained
Windows x64 publishing, dependency-notice collection and WiX MSI validation passed;
the MSI version and SHA-256 checksum verify. Installer lifecycle checks have not been repeated for this version.
Ordinary nonadministrator installation, installed real-app/UAC cancellation,
Narrator and physical-monitor checks remain separate validation limits.

The MSI and application are unsigned. This version has not yet been published on
GitHub; the latest public download remains 0.2.2 Preview.
