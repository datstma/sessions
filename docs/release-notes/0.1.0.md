# Sessions 0.1.0 — Preview

First Windows x64 installer preview of Sessions.

Save a named set of apps, start them in order, and end the Session with confirmed
cleanup of apps Sessions owns. Includes the searchable Start menu/running-app
picker, local storage, light/dark appearance, and individual app launching.

## Installation

Download `Sessions-0.1.0-win-x64.msi` and run it under your normal Windows user.
The MSI includes .NET. It installs for that user and adds a Start menu shortcut.
Close Sessions before installation, upgrades, or uninstalling.
Saved Sessions are stored in `%LOCALAPPDATA%\Sessions\sessions.json` and are
preserved during upgrades and uninstall.

## Preview limitations

- Windows x64 only; other platforms/architectures are not packaged.
- Installer and application binaries are unsigned.
- No automatic updater; install a newer MSI to update.
- Microsoft Store/packaged-app activation is not supported.
- Save work before confirming End Session: owned apps that remain open can be
  force quit. Apps already open before the Session remain independent.

## Validation

Windows Sandbox checks passed for installation and launch without a separately
installed .NET runtime, upgrade, downgrade rejection, uninstall/reinstall, library
preservation, and running-app refusal during silent upgrade and uninstall.
An ordinary nonadministrator account and installed real-app/UAC cleanup remain
unverified for this preview.

The 2026-09-09 checks used the default Windows Sandbox account and a test-only
0.1.1 MSI to exercise upgrade mechanics. All 81 regular app/Core tests pass; the
20 opt-in native regression checks were not rerun. Fresh MSI operations took about
two minutes in the offline Sandbox; the cause has not been established.

## Source and checksums

`Sessions-0.1.0-source.zip` contains this release's Sessions source and build scripts.
Sessions uses GPL-3.0-only; dependency licenses are included in the installed
`licenses` directory. `WiX-7.0.0-source.zip` supplies the matching source for the
installer's WiX utility action under MS-RL. See `docs/RELEASING.md` in the Sessions
archive for build instructions. `SHA256SUMS.txt` covers the MSI and both ZIPs.

To check the installer in PowerShell, compare the result with `SHA256SUMS.txt`:

```powershell
Get-FileHash .\Sessions-0.1.0-win-x64.msi -Algorithm SHA256
```
