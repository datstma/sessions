# Sessions 0.2.1 — Preview

A refreshed Sessions, with the same app startup, ownership and stopping behavior.

## What's new

- A consistent Sessions identity: cascading-square logo, bundled Manrope type,
  indigo primary actions, green running states and red destructive actions.
- Rounded Session headers and app cards, plus matching editor, app picker and
  confirmation screens in both system-selected themes.
- A clearer End confirmation: **Will be closed** and **Stays open** lists show
  which apps belong to the Session and which were already running.
- Branded executable, window, Start menu and Installed apps icons. The old
  Avalonia template icon and Inter font package have been removed.
- A screenshot-led GitHub README with the Sessions logo and real UI views.

Compact 640×480 layouts, keyboard navigation, advanced startup options and existing
validation/recovery behavior remain supported. No new Session actions or saved
settings are introduced.

## Upgrading

Close Sessions and run `Sessions-0.2.1-win-x64.msi`. The per-user
installer includes .NET and preserves your saved Sessions. There is no automatic
updater.

**0.2.1 uses the same v2 library format as 0.2.0.** If you are upgrading from
0.1.0, loading your library does not rewrite it; saving upgrades it to v2, which
0.1.0 cannot open. Keep a copy of `%LOCALAPPDATA%\Sessions\sessions.json` before
saving if you need to return to 0.1.0.

## Preview limitations

- Windows x64 only; installer and application binaries are unsigned.
- Save your work before confirming End: owned apps still running after a normal
  close can be force quit. Already-running apps remain independent.
- Microsoft Store/packaged-app activation and general launcher handoffs remain
  unsupported. Readiness checks do not prove loading or sign-in has finished.
- General unsaved-draft protection outside an active Session is still pending.
- Native screen-reader output, physical monitor/DPI changes, Windows text sizing,
  ordinary nonadministrator installation and installed real-app/UAC behavior need
  further hands-on verification.

## Validation

[The release workflow](https://github.com/datstma/sessions/actions/runs/34398030125)
built tag `v0.2.1` (commit `863f75d`). Release solution/MSI builds passed with
zero build warnings or errors, 45 Core tests and 94 App tests. The regular suite skips
22 opt-in native tests. Both themes were rendered at 1440×900 and 640×480, with
existing 125%/150%/200% scaling and keyboard coverage. Public screenshots use
isolated sample data and simulated process state.

All downloaded asset checksums verify, and all 160 entries of the Sessions source
archive match the tag. The MSI contains 272 payload files; all 42 package metadata
and notice files match the reviewed local package, allowing checkout line endings.
The icon references and preserved Manrope license verify; the old Inter package
and supplemental notice are absent. The WiX source archive matches its pinned
source commit and license. GitHub's Markdown renderer preserves the README layout
and image sources; its local links, images and navigation anchors verify.

The exact downloaded MSI passed 34 Sandbox checks plus the initial 0.2.0 baseline
install: upgrade to 0.2.1, installed launch without shared .NET, one per-user
registration, exact release-commit metadata, running-app refusal, downgrade
rejection, uninstall/reinstall and byte-for-byte library preservation. The upgrade
removes the old Inter files and installs the Manrope notice. Installed apps and
Start menu icon registrations resolve to an icon that decodes as the Sessions mark.
The icon test was corrected to query Windows Installer's registration API and
resumed after the successful upgrade; no installer fix was needed.

These tests used the default Sandbox account and isolated fixtures. Ordinary
nonadministrator installation, real-app/UAC cleanup and native accessibility/display
checks remain unverified. Some offline MSI operations again took about two minutes;
no installation-speed claim is made.

## Source and checksums

`Sessions-0.2.1-source.zip` contains the matching Sessions source and build scripts.
Sessions uses GPL-3.0-only; dependency licenses are installed in `licenses`.
`WiX-7.0.0-source.zip` supplies the installer utility action's matching MS-RL source.
`SHA256SUMS.txt` covers the MSI and both ZIPs. Build instructions are in
`docs/RELEASING.md` in the source archive.

```powershell
Get-FileHash .\Sessions-0.2.1-win-x64.msi -Algorithm SHA256
```
