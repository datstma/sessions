# Sessions 0.2.0 — Preview

Control how your Session starts, with improved keyboard access and compact layouts.

## What's new

- Open apps in order or all at once. Set pauses between apps and per-app overrides.
- Choose each app's startup condition: launch request completed, process running,
  or window appeared. Readiness waits have configurable timeouts and countdowns.
- Optionally bring Sessions or a chosen app forward once startup succeeds.
- Options headings follow the selected app and Session names as you edit them.
- Empty Sessions stay editable; Start Session appears after you add and save apps.
- Improved accessibility names, keyboard focus restoration, status announcements,
  and layouts down to 640×480, with scrolling for long content.

## Upgrading from 0.1.0

Close Sessions, then run `Sessions-0.2.0-win-x64.msi`. The installer updates the
per-user installation and preserves your saved library. .NET is included.

**Saving in 0.2.0 upgrades your library to format v2. Sessions 0.1.0 cannot open
that format.** Existing libraries load with their previous startup defaults;
loading alone does not rewrite them. Keep a copy of
`%LOCALAPPDATA%\Sessions\sessions.json` before saving if you need to return to 0.1.0.

## Preview limitations

- Windows x64 only. Installer and application binaries are unsigned.
- No automatic updater; install a newer MSI to update.
- Process/window readiness does not prove loading or sign-in has finished. The
  timeout begins after Windows returns the launch request and does not dismiss UAC.
- Windows may decline foreground activation. Failure to focus does not fail startup.
- All at once ignores pauses; repeated entries for one executable stay ordered.
- Microsoft Store/packaged-app activation and general launcher handoffs remain
  unsupported. Untracked launches cannot satisfy process/window readiness checks.
- Save work before confirming End Session: owned apps that remain open can be
  force quit. Apps already open before the Session remain independent.
- Native screen-reader delivery, physical DPI/monitor transitions, ordinary
  nonadministrator installation, and installed real-app/UAC cleanup still need
  hands-on verification.

## Validation

Source validation passes a clean Release build, 45 Core and 90 regular App tests.
The regular suite skips 22 opt-in native cases. A separate run passed all 17 native
runtime fixtures, including readiness in both launch modes and process ownership,
cleanup, and self-restart checks. Keyboard/layout checks cover both themes and
small windows with long content. Tests use isolated libraries and process fixtures.

Exact tagged installer and downloaded-asset verification results are recorded in
the GitHub release notes before publication.

## Source and checksums

`Sessions-0.2.0-source.zip` contains the matching Sessions source and build scripts.
Sessions uses GPL-3.0-only; dependency licenses are installed in `licenses`.
`WiX-7.0.0-source.zip` supplies the installer utility action's matching MS-RL source.
`SHA256SUMS.txt` covers the MSI and both ZIPs. Build instructions are in
`docs/RELEASING.md` in the source archive.

```powershell
Get-FileHash .\Sessions-0.2.0-win-x64.msi -Algorithm SHA256
```
